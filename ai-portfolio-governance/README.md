# AI Portfolio Governance

Portfolio-level governance model for the fictional **Northstar Enterprise AI Transformation Program**.

This repository demonstrates how a Senior AI Technical Project Manager can oversee multiple concurrent GenAI and AI/ML initiatives while giving executives a concise, decision-oriented view of delivery health.

## Portfolio snapshot
| Initiative | Type | Health | Budget | Primary Risk |
|---|---|---|---:|---|
| Customer Support Copilot | RAG / GenAI | Green | $450K | Retrieval quality |
| Contract Intelligence Assistant | GenAI | Yellow | $310K | Data classification |
| Predictive Maintenance | ML | Green | $600K | Data readiness |
| Sales AI Agent | Agentic AI | Yellow | $220K | Tool authorization |
| Fraud Detection Modernization | ML | Green | $720K | Model drift |

## Governance cadence
- Weekly workstream reviews
- Biweekly cross-program dependency forum
- Monthly executive steering committee
- Quarterly portfolio reprioritization

## Portfolio controls
- Standard health definitions
- RAID escalation thresholds
- Dependency ownership
- Forecast vs. approved budget tracking
- Milestone confidence
- AI-specific production gates
- Executive decisions and actions log

> All projects, figures and metrics are fictional portfolio examples.
