# AI Program Risk Dashboard

Streamlit prototype for executive visibility across the fictional Northstar AI portfolio.

## Dashboard views
- Portfolio health by initiative
- Approved vs forecast budget
- Schedule variance
- Executive-attention items
- AI-specific quality / operational metrics
- Portfolio risk register

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## TPM purpose
The dashboard is not intended to replace Jira/ServiceNow/Smartsheet. It demonstrates how delivery data can be consolidated into a decision-oriented executive view.
