# Agentic AI Governance

Reference governance design for a fictional **AI Procurement Assistant** that can search policy and vendor information, analyze options, and propose actions while remaining constrained by enterprise authorization rules.

## Core principle
The agent may **recommend broadly but act narrowly**. Higher-risk actions require explicit authorization and human approval.

## Demonstrates
- Agent/tool boundary design
- Human-in-the-loop controls
- Risk-based authorization
- Runtime policy enforcement concepts
- Auditability and escalation
- AI-specific RAID and release gates

> Demonstration design only. No live enterprise transaction system is connected.
