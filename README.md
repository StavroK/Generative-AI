# Senior AI Technical Project Manager Portfolio

A portfolio demonstrating enterprise delivery leadership across Generative AI, AI/ML, AWS, portfolio governance, LLMOps, agentic AI controls, executive reporting, and Agile delivery.

## Northstar Enterprise AI Transformation Program

This portfolio is organized around a fictional enterprise transformation program called **Northstar**. The objective is to show how a Senior AI Technical Project Manager can translate business priorities into governed, production-oriented AI initiatives.

### Portfolio initiatives
1. **Enterprise RAG on AWS** — reference architecture, backlog, release plan, Terraform starter, AI evaluation, security and production-readiness artifacts.
2. **AI Portfolio Governance** — multi-project dashboard, RAID, dependency map, executive steering report, budget and resource governance.
3. **Agentic AI Governance** — tool-use controls, human approvals, runtime policy enforcement, auditability and escalation design.
4. **LLMOps Delivery Framework** — lifecycle gates from discovery to production monitoring with measurable exit criteria.
5. **AI Program Risk Dashboard** — Streamlit dashboard prototype for portfolio health, AI KPIs, risks and delivery trends.
6. **AI Project Manager Playbook** — reusable project charter, RACI, sprint, status, risk, release and incident templates.

## What this portfolio demonstrates
- Portfolio-level oversight and executive reporting
- End-to-end GenAI and AI/ML delivery planning
- AWS technical fluency: Bedrock, SageMaker, Lambda, S3, OpenSearch, API Gateway, CloudWatch, IAM, KMS
- Agile/Scrum operating cadence
- Cross-project dependency and resource management
- AI-specific risk management and production-readiness criteria
- LLMOps / MLOps governance
- AI agent safety and human-in-the-loop controls

> All business names, budgets, metrics and scenarios are fictional and created for demonstration purposes.
