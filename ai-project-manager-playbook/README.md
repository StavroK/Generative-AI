# AI Technical Project Manager Playbook

Reusable operating artifacts for enterprise GenAI / AI-ML delivery.

## Contents
- AI project charter
- RACI
- RAID log
- Executive status report
- Sprint planning / review / retrospective
- Architecture decision log
- AI evaluation plan
- Production-readiness review
- AI incident review
- Steering committee decision log

The goal is a lightweight operating system: enough governance to make delivery predictable without burying engineering teams in process.
