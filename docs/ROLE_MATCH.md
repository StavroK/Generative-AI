# Role-to-Portfolio Evidence Matrix

Target role: **Senior AI Technical Project Manager (GenAI / AI-ML / AWS)**

| Role requirement | Portfolio evidence |
|---|---|
| End-to-end GenAI / AI-ML delivery | Enterprise RAG: business case → architecture → backlog → evaluation → production-readiness → release |
| Portfolio governance | Five-initiative portfolio, health model, budget, capacity, RAID, steering report |
| Executive dashboards and reporting | AI Program Risk Dashboard + executive status report |
| Agile / Scrum ceremonies | AI TPM Playbook |
| Scope, timeline, budget, dependencies, risks | Portfolio roadmap, forecast, RAID, dependency map, capacity view |
| Proactive risk mitigation and escalation | Project/portfolio RAID logs, decision deadlines, steering escalation paths |
| Cross-project dependencies and resource conflicts | Dependency map and resource-capacity view |
| LLM / RAG understanding | AWS RAG architecture, retrieval backlog, evaluation metrics |
| AI Agents | Governed procurement agent, tool policy, approval matrix, runtime controls |
| MLOps / LLMOps | Lifecycle gates, change management, incident response, KPI catalog |
| AWS: Bedrock / SageMaker / Lambda / S3 / OpenSearch | RAG architecture and delivery design |
| Production deployment readiness | Production-readiness checklists, release plan, rollback triggers, support model |

## Interview positioning
"I use technical depth to make better delivery decisions—not to replace the engineers. My job is to connect business outcomes, architecture, Agile execution, AI evaluation, risk controls, and executive governance so AI initiatives reach production predictably."
