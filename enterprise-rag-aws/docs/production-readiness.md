# Production Readiness Gate

## Business
- [ ] Named product owner and operations owner
- [ ] Pilot population defined
- [ ] Success KPIs baselined

## AI Quality
- [ ] Groundedness target passed
- [ ] Citation precision target passed
- [ ] Unsupported-answer threshold passed
- [ ] Adversarial/prompt-injection scenarios tested

## Security
- [ ] IAM review complete
- [ ] Data classification approved
- [ ] Encryption validated
- [ ] No unresolved critical/high launch-blocking findings

## Operations
- [ ] SLOs defined
- [ ] CloudWatch dashboard and alarms active
- [ ] Incident and rollback runbooks approved
- [ ] Support/escalation model staffed

## Financial
- [ ] Usage assumptions documented
- [ ] Cost dashboard operational
- [ ] Budget alerts configured
