# Politique de Préparation à la Production IA

Avant qu’une solution IA Northstar entre en pilote de production contrôlé :

- le responsable métier doit approuver l’usage prévu ;
- les seuils d’évaluation IA doivent être atteints ou une exception documentée ;
- les contrôles d’accès et la classification des données doivent être vérifiés ;
- la supervision, la gestion des incidents et les procédures de retour arrière doivent être actives ;
- aucun problème de sécurité bloquant ne doit rester ouvert ;
- les hypothèses de coût et les alertes d’usage doivent être documentées.

Un échec de la revue bloque le lancement jusqu’à correction ou exception autorisée.
