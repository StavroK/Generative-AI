# Standard de Gouvernance du Portefeuille IA

Le portefeuille Northstar est revu à trois niveaux : revue hebdomadaire des workstreams, revue bimensuelle des dépendances et comité exécutif mensuel.

Les projets rapportent le périmètre, la confiance dans les jalons, le budget prévisionnel, les dépendances, les éléments RAID et les mesures de qualité ou d’exploitation IA.

Un statut Jaune nécessite une attention managériale mais reste récupérable. Un statut Rouge signifie qu’un engagement majeur risque de ne pas être tenu sans intervention exécutive, replanification ou changement de périmètre.
