# Política de Acciones de Agentes de IA

Los agentes de IA Northstar siguen una política basada en riesgo.

Las acciones de búsqueda de solo lectura pueden automatizarse cuando el usuario está autorizado.

Las acciones que crean compromisos, envían comunicaciones externas, cambian datos maestros o ejecutan transacciones financieras requieren autorización explícita y pueden requerir aprobación humana.

Si la autorización es ambigua, el agente debe detenerse en lugar de inferir permiso.

Las acciones de alto impacto deben generar un evento auditable con usuario, herramienta, acción, decisión y resultado.
