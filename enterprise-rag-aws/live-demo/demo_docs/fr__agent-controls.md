# Politique d’Action des Agents IA

Les agents IA Northstar suivent une politique fondée sur le risque.

Les recherches en lecture seule peuvent être automatisées pour un utilisateur autorisé.

Les actions créant un engagement, envoyant une communication externe, modifiant des données de référence ou exécutant une transaction financière exigent une autorisation explicite et peuvent nécessiter une approbation humaine.

Si l’autorisation est ambiguë, l’agent doit s’arrêter plutôt que déduire une permission.

Toute action à fort impact doit produire un événement auditable.
