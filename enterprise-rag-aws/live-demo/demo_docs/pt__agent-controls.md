# Política de Ações de Agentes de IA

Os agentes de IA Northstar seguem uma política baseada em risco.

Ações de pesquisa somente leitura podem ser automatizadas para usuários autorizados.

Ações que criam compromissos, enviam comunicações externas, alteram dados mestres ou executam transações financeiras exigem autorização explícita e podem exigir aprovação humana.

Se a autorização for ambígua, o agente deve parar em vez de inferir permissão.

Toda ação de alto impacto deve gerar um evento auditável.
