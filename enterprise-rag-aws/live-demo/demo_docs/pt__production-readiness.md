# Política de Preparação para Produção de IA

Antes de uma solução de IA Northstar entrar em um piloto controlado de produção:

- o responsável de negócio deve aprovar o uso;
- os limites de avaliação de IA devem ser atingidos ou uma exceção documentada;
- controles de acesso e classificação de dados devem ser revisados;
- monitoramento, responsabilidade por incidentes e procedimentos de rollback devem estar ativos;
- não pode haver achado de segurança bloqueante;
- premissas de custo e alertas de uso devem estar documentados.

Uma falha na revisão bloqueia o lançamento até a correção ou uma exceção autorizada.
