# Estándar de Gobierno de Costos de IA

Northstar administra el costo de IA como una métrica de entrega.

Cada proyecto reporta pronóstico mensual, consumo de tokens o inferencias, costo por 1,000 solicitudes, costo por tarea de negocio y variación contra pronóstico.

Las alertas de uso se configuran antes de producción.

Cuando el costo excede el umbral aprobado, las acciones pueden incluir optimización de prompts, ajuste de recuperación, cambio de modelo, caching, controles de tráfico o cambio de alcance.
