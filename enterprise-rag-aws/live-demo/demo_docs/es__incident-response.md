# Respuesta a Incidentes de IA

Un incidente de IA es cualquier evento con impacto o riesgo material de negocio, seguridad, cumplimiento, finanzas o cliente.

Ejemplos: exposición de datos protegidos, bypass de autorización, contenido dañino, aumento sostenido de respuestas no respaldadas, consumo descontrolado de tokens o caída del proveedor de modelo.

La secuencia de respuesta es: contener, preservar evidencia, evaluar impacto, comunicar, recuperar y realizar una revisión posterior con mejoras medibles de control.
