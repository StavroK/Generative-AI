# Lifecycle Gates

## Gate 0 — Intake
- Named business owner
- Problem and target users defined
- Baseline process metric available
- AI is justified versus deterministic automation

## Gate 1 — Data & Architecture Readiness
- Data owner identified
- Data classification complete
- Source quality assessed
- Reference architecture reviewed
- Cost assumptions documented

## Gate 2 — Evaluation Readiness
- Versioned evaluation dataset
- Success thresholds approved
- Failure categories defined
- Prompt/model/retrieval versions traceable

## Gate 3 — Security & Responsible AI
- Threat model reviewed
- Prompt-injection and data leakage tests complete
- Authorization boundaries tested
- Human oversight defined where required

## Gate 4 — Production Readiness
- UAT accepted
- SLOs and monitoring active
- Incident and rollback runbooks approved
- Support ownership active
- Budget alerts configured

## Gate 5 — Scale Decision
- Business outcome evidence
- AI quality stable
- Unit economics acceptable
- Operational load understood
- Risks within approved tolerance
